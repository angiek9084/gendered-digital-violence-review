# Data dictionary for planned release

## Corpus (350 records)
`record_id`: fixed publication ID.
`publication_year`: reported year.
`title`: standardized bibliographic title.
`doi`: DOI where reported.
`authors_as_exported`: source metadata; may contain initials or be empty.
`source_title`: journal, publisher or other venue.
`document_type_as_exported`: source document-type category.
`original_database`: source dataset(s), Scopus and/or Web of Science.
