# Publication data release — 350-record corpus

This directory documents the planned release accompanying the paper on gendered digital violence against women politicians, journalists and academics.

**Current status:** publication package prepared but NOT YET uploaded in full. The repository is currently private and does not have a dataset DOI. The 350-record bibliography, source tables and figure images are available in a separate curated release archive prepared by the research team. **Do not treat this folder as an openly accessible completed dataset.**

## Release archive contents (prepared separately)
- A 350-record bibliographic CSV containing record ID, year, title, DOI, author string, venue, document type and original Scopus / Web of Science source.
- Six descriptive bibliometric figure-data CSV files.
- Aggregated first-authorship gender counts and verification summary.
- Six bibliometric figures and one first-authorship figure.
- Documentation of denominators and known limitations.

No full texts or substantial abstracts are redistributed. Preliminary machine-classified violence-type and methods fields are **not** included as final human-validated data.

**Before journal submission:** upload the contents of the curated archive to this publication directory, verify every figure against the accepted manuscript, inspect the entire repository for restricted material, make the repository public, and archive a tagged release in Zenodo for a permanent DOI.
