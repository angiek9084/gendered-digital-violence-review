# Proposed data availability statement (Spanish)

Los datos bibliográficos y los materiales de análisis que respaldan los hallazgos de este estudio se están preparando para su publicación en un repositorio de GitHub: https://github.com/angiek9084/gendered-digital-violence-review. El repositorio incluirá la base definitiva de 350 publicaciones, la documentación metodológica, las tablas agregadas que sustentan las figuras y las imágenes utilizadas en el artículo. **El repositorio es todavía privado y el conjunto definitivo aún no está publicado; no declarar acceso abierto hasta verificarlo.** Una versión estable podrá archivarse posteriormente con DOI en Zenodo.
