# Gendered Digital Violence Review

This repository provides the bibliographic data and supporting materials for a study of academic research on gendered digital violence against women politicians, journalists, and academics.

## Dataset

The final corpus comprises 350 publications covering the period 2016–2026, retrieved from Scopus and Web of Science and subjected to bibliographic deduplication and eligibility screening.

## Research materials

The publication directory contains the bibliographic dataset, aggregated results, figures, and methodological documentation supporting the study.

## Reproducibility

Data dictionaries and supporting tables are provided to facilitate interpretation and reproducibility. Materials subject to copyright restrictions are not redistributed.

## Citation

Please cite the associated academic article when using these materials.
